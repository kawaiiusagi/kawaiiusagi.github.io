## 한 줄 요약
> 저조도 향상을 "이미지별 밝기 조절 곡선을 추정하는 문제"로 재정의하고, **정답 이미지 없이(zero-reference)** 4개의 손실함수만으로 학습되는 가볍고 빠른 모델.

## 핵심 아이디어 — LE-curve (Light-Enhancement Curve)

### 기본 곡선식 (Eq.1)
```
LE(I(x); α) = I(x) + α · I(x) · (1 - I(x))
```
- 포토샵 커브 조정 기능에서 영감을 받은 방식. 직선(y=x)을 볼록하게 구부려서 어두운 픽셀을 더 많이 밝힘
- `I(x)·(1-I(x))` 항 덕분에 **중간 밝기에서 조정 효과가 크고, 극단(0 또는 1)에서는 거의 조정 안 됨** → 이미 어둡거나 밝은 곳은 자동으로 보호됨

### 곡선 설계 3원칙
1. 출력값이 [0,1] 범위 유지 (overflow 방지)
2. **단조성(monotonicity)** 유지 → 이웃 픽셀 간 명암 대비(contrast) 보존
3. 단순하고 미분 가능(differentiable) → 신경망 학습 가능

### 진화 과정: 스칼라 → 반복 → 픽셀 단위
| 버전 | 수식 | α의 형태 |
|---|---|---|
| Eq.(1) 기본 | `LE(I; α)` | 숫자 1개 (전역) |
| Eq.(2) 고차(High-order) 곡선 | `LEₙ = LEₙ₋₁ + αₙ · LEₙ₋₁ · (1 - LEₙ₋₁)` | 숫자 8개 (반복해도 여전히 전역) |
| Eq.(3) 픽셀별(Pixel-wise) 곡선 | `LEₙ(x) = LEₙ₋₁(x) + Aₙ(x) · LEₙ₋₁(x) · (1 - LEₙ₋₁(x))` | **이미지 크기의 맵** (픽셀마다 다른 값) |

- **반복(iteration, n=8)**: 곡선을 여러 번 누적 적용해서 조정 가능한 다이나믹 레인지(명암 폭)를 넓힘. 1회만 적용하면 성능 급감 (Ablation에서 확인)
- **픽셀 단위(A)로 바꾼 이유**: 전역 α 하나만 쓰면 이미지 내 밝기 편차가 큰 경우 특정 부위가 과다/부족 노출됨 → 픽셀마다 자기 상황에 맞는 α를 갖게 해서 해결
- **R/G/B 각 채널별로 독립적으로 계산 후 재조합**: 조명(illumination) 채널 하나만 조정하지 않고 3채널 각각 따로 곡선 적용 → 색 왜곡·과다노출 위험 감소. 세 채널의 균형은 Color Constancy Loss가 별도로 잡아줌

## DCE-Net 구조 (3.2절)
- **7개의 합성곱(Conv) 레이어**, 각 레이어 32개의 3×3 커널, stride 1
- **Symmetrical concatenation (대칭 연결/skip connection)**: 앞쪽 레이어 출력을 뒤쪽 레이어에 다시 이어붙여서, 세밀한 디테일 정보가 깊은 레이어까지 보존되게 함
- **Down-sampling·Batch normalization 의도적으로 제외**: 이웃 픽셀 관계가 깨지는 걸 방지 (Spatial Consistency Loss 취지와 일치)
- **활성화 함수**: 중간 레이어엔 ReLU(비선형성 부여), 마지막 레이어엔 Tanh(출력을 α 유효범위 [-1,1]로 맞춤)
- 출력: 24장의 파라미터 맵 (8회 반복 × R/G/B 3채널)
- **매우 가벼움**: 파라미터 79,416개, FLOPs 5.21G (입력 256×256×3 기준)

## Non-Reference Loss Functions (3.3절, 정답 이미지 없이 학습 가능하게 하는 핵심)

| 손실함수 | 수식 핵심 | 역할 |
|---|---|---|
| **Spatial Consistency Loss** (L_spa) | 이웃 4방향 지역 간 밝기 차이를, 원본과 향상본에서 비슷하게 유지 | 구조·명암 대비가 깨지지 않게 함 |
| **Exposure Control Loss** (L_exp) | 각 16×16 지역의 평균 밝기와 목표 노출값(E=0.6) 사이의 거리 | 너무 어둡거나 밝지 않게, 적정 노출 유도 |
| **Color Constancy Loss** (L_col) | R,G,B 채널 간 평균 밝기 차이 (Gray-World 가설 기반) | 색 왜곡(color cast) 방지 |
| **Illumination Smoothness Loss** (L_tvA) | 파라미터 맵 A의 픽셀 간 기울기(gradient) | α맵이 매끄럽게 변하도록 해 아티팩트 방지 |

**Total Loss**:
```
L_total = L_spa + L_exp + W_col · L_col + W_tvA · L_tvA
```
가중치 W_col = 0.5, W_tvA = 20 (손실들의 스케일 균형을 맞추기 위한 보정 계수)

## 학습 설정
- SICE 데이터셋의 다중노출 이미지 360세트 (저노출+과노출 함께 사용 — 과노출 데이터 빼면 밝은 영역을 오히려 과다 향상시키는 부작용 발생, Fig.6에서 검증됨)
- PyTorch, 2080Ti GPU, batch size 8, ADAM(lr=1e-4)

## 실험 결과 핵심

**Ablation Study (Fig.4, Fig.5)**
- 4개 손실함수 중 하나라도 빼면: 대비 저하 / 저조도 미복원 / 색 왜곡 / 아티팩트 중 하나가 발생 → 4개 모두 필요함을 실증
- 반복 횟수 1로 줄이면 성능 급감 → 고차 곡선(반복)의 필요성 재확인
- 최종 모델: 7개 레이어, 반복 8회 (`7-32-8`) — 효율성과 성능의 최적 균형

**Benchmark Evaluations**
- PSNR/SSIM/MAE 등 정량 지표에서 SRIE/LIME/RetinexNet/EnlightenGAN 등 기존 방법 대비 **최고 성능**, 그것도 정답 데이터 없이 달성
- **런타임 압도적으로 빠름**: 0.0025초 (타 방법 대비 수십~수만 배)

**Face Detection in the Dark (4.2.3)** — 실용성 증거
- DARK FACE 데이터셋 + DSFD 얼굴 탐지기로 실험
- Zero-DCE로 향상 후 탐지 정밀도가 원본 대비 뚜렷이 상승 → **화질 향상이 실제 인식 성능 개선으로 이어짐을 실증**한 사례

## 결론 (5절)
- 정답 이미지 없이 end-to-end 학습 가능한 저조도 향상 모델 제안
- 향후 계획: 노이즈 고려, semantic 정보 활용 예정
